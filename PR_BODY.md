## 🏗️ Доработки организации + штатное расписание (production-ready)

### 1. Организационно-правовая форма — свободный ввод
- В форме создания организации добавлены **КГБУЗ, ФГБУЗ, КГБУ, ГБУЗ, ГКУ, МБДОУ, МБОУ, ГАУ, МУП, ГУП** и др.
- Пункт **«Другая форма — указать вручную…»** — можно вписать любую ОПФ руками.
- В карточке организации (редактирование) поле ОПФ тоже стало combobox (datalist): подсказки + ручной ввод.

### 2. Убрано поле «Главный бухгалтер»
- Удалено из формы создания, карточки и типов; бухгалтер заводится как обычный сотрудник.
- Миграция данных: у существующих организаций старое поле вычищается из localStorage.

### 3. Штатное расписание (чинит пустые списки «Должность/Отдел/Филиал» у сотрудников)
- Новая страница **«Штатное расписание»** (`/directories`): справочники Отделы / Должности / Филиалы (CRUD, привязка к организации).
- Справочники автоматически привязываются к организации пользователя и фильтруются по ней.
- При пустых справочниках в окне добавления сотрудника — подсказка с кнопкой перехода в «Штатное расписание».
- Новый пункт в сайдбаре.

### 4. Деплой (из прошлых итераций, уже проверено на сервере)
- `.npmrc` с таймаутами/retry, поддержка `NPM_REGISTRY`/прокси в Dockerfile и compose, автоопределение docker-compose v1/v2 в deploy.sh, убран устаревший `version:` из compose.

### ✅ Проверки
- `tsc --noEmit` (frontend + backend) — без ошибок; `npm run build` — успешно
- Сервис стартует полностью пустым: демо-учётных записей и тестового наполнения нет
- В репозитории остаются только исходники (node_modules/dist исключены из трекинга)
